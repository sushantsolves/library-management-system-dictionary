📚 Library Management System (Dictionary-Based)

🔹 Overview
A modular Library Management System built using Python that uses a dictionary for efficient book management and a structured CLI interface.


🚀 Features
* Add books with quantity
* Issue and return books
* Display available books
* Modular design using multiple files


🛠️ Tech Stack
* Python
* Dictionary Data Structure


▶️ How to Run

python main.py


🔄 Improvement Over Previous Version
* Faster lookup using dictionary (O(1))
* Better structure with modular files
* More efficient than list-based approach


🚧 Future Improvements
* File handling (data persistence)
* User authentication
* Enhanced UI
